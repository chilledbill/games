# Closing Fantasy

Portrait, one-handed tactical action RPG prototype. Combat feel test build: click an enemy on the map to approach and fight, defeat all four (Grunt, Archer, Defender, Berserker).

**Controls (PC):** J light · K heavy · Space parry · A/D dodge · Q/E switch target · Tab map · P pause · W wait on map
**Testing:** T tuning panel · B A/B against v0.4 · N no damage · O slow-mo · Isolate effects panel (left) to solo/mute effect layers

Current build: v0.23 (see the Build notes panel in game).
